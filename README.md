# VRPT-EscapeTheClassroom

## Projektbeschreibung

**EscapeTheClassroom** ist ein kooperatives Virtual-Reality-Escape-Spiel zum Thema **Codes und Codierung**.

Zwei Spieler:innen versuchen gemeinsam, aus einem virtuellen Klassenzimmer zu entkommen.

Eine Person befindet sich mit einer VR-Brille im Klassenzimmer, während die zweite Person außerhalb der virtuellen Welt unterstützt.

Nur durch Kommunikation, Zusammenarbeit und das richtige Entschlüsseln von Codes kann das Spiel erfolgreich abgeschlossen werden.

## Zielgruppe

Schüler:innen der Mittelschule (ca. 10–14 Jahre).

Das Spiel soll ohne Vorkenntnisse verständlich sein, Spaß machen und spielerisch Interesse an Informatik wecken.

## Spielprinzip

- **Person in VR:** Erkundet den virtuellen Raum, entdeckt Hinweise und interagiert mit Gegenständen.
- **Person außerhalb der VR:** Erhält zusätzliche Informationen und unterstützt beim Entschlüsseln der Codes.
- **Gemeinsames Ziel:** Einen Code knacken und die Klassenzimmertür öffnen.

Beide Personen verfügen über unterschiedliche Informationen. Keine Person kann das Rätsel alleine lösen.

## Anforderungen

### Funktionale Anforderungen

1. Das Spiel findet in einem virtuellen Klassenzimmer statt.
2. Das Kernthema ist Codes und Codierung.
3. Es gibt mindestens ein kooperatives Rätsel.
4. Das Rätsel soll innerhalb von 2–3 Minuten lösbar sein.
5. Die gesamte Spielrunde darf maximal 5 Minuten dauern.
6. Die Person in VR kann Gegenstände untersuchen und mit ihnen interagieren.
7. Die Person außerhalb der VR erhält zusätzliche Informationen, die für die Lösung benötigt werden.
8. Beide Spieler:innen müssen miteinander kommunizieren.
9. Bei richtiger Lösung erfolgt eine sichtbare oder hörbare Rückmeldung.
10. Nach erfolgreicher Lösung öffnet sich die Klassenzimmertür.

### Nichtfunktionale Anforderungen

- **Spielspaß:** Das Spiel soll spannend, überraschend und motivierend sein.
- **Verständlichkeit:** Ohne Informatik-Vorkenntnisse spielbar.
- **Bedienbarkeit:** Einfache und intuitive VR-Interaktionen.
- **Spieldauer:** Maximal 5 Minuten inklusive Einführung und Abschluss.
- **Zielgruppengerecht:** Für Mittelschüler:innen geeignet.
- **Kollaboration:** Beide Personen tragen aktiv zur Lösung bei.
- **Motivation:** Erfolgserlebnisse und unmittelbares Feedback.
- **Wiederspielbarkeit (optional):** Unterschiedliche Codes oder Rätselvarianten.

## Fachlicher Schwerpunkt: Codes und Codierung

### Was ist ein Code?

Ein Code ist ein System aus Zeichen, Symbolen oder Signalen, denen nach festgelegten Regeln eine Bedeutung zugeordnet wird.

Beispiele:
- Morsecode
- Binärcode
- QR-Code
- Emojis und Symbole
- Caesar-Verschlüsselung

### Was bedeutet Codierung?

Codierung ist die Umwandlung von Informationen in eine bestimmte Darstellung nach festgelegten Regeln.

Ein Beispiel:

Der Buchstabe `A` kann unterschiedlich dargestellt werden:

- Als Zeichen: `A`
- Im ASCII-Code (8 Bit): `01000001`
- Als Morsecode: `·−`

## Beispielrätsel: Der geheime Türcode

Im virtuellen Klassenzimmer befinden sich mehrere Gegenstände mit geheimnisvollen Symbolen.

Die Person in VR entdeckt diese Symbole und beschreibt sie.

Die Person außerhalb der VR besitzt eine Codetabelle, mit der die Symbole in Zahlen übersetzt werden können.

Gemeinsam ermitteln die Spieler:innen einen Zahlencode.

Die Person in VR gibt den Code ein und öffnet damit die Klassenzimmertür.

**Lernziel:** Informationen können unterschiedlich dargestellt werden. Um einen Code zu verstehen, muss man seine Regeln kennen.
